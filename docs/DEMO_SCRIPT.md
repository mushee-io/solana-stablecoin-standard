# Demo Script

1. Open the Issuer Dashboard home page
2. Show an SSS-2 deployment overview
3. Create a mint request above the threshold
4. Show policy simulation requiring approval
5. Approve the request
6. Execute the mint and show audit entry
7. Add a wallet to the blacklist
8. Explain how transfer hook blocks future transfers
9. Execute seizure and show treasury result
10. Export audit log as CSV
